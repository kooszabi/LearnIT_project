LearnIT

Interactive web application for learning Python programming

LearnIT is my Bachelor's thesis project developed to help beginners learn the fundamentals of Python programming through interactive lessons, quizzes, coding exercises, AI-generated flashcards, and progress tracking.

The goal of the project is to provide an engaging learning experience while allowing users to monitor their development and reinforce their knowledge with modern AI-assisted learning tools.

Features
- User registration and authentication
- Structured programming lessons
- Multiple-choice quizzes
- Coding exercises
- AI-assisted code evaluation
- AI-generated flashcards
- Learning progress statistics
- Topic completion tracking
- Personalized learning experience
